ALIEN REACT STUDIO — experimental v1
Ubuntu: unzip, open terminal in folder, run bash START.sh. Use Chrome or Chromium at http://localhost:8765. Keep terminal open. Internet needed for MediaPipe model and runtime. Open source tab, enable alien, select source tab with audio, start recording. Keep recorder visible in a separate window (background tabs can throttle animation). Use headphones. Finish saves WebM, accepted by YouTube. Test a short recording first. Recording is buffered in RAM; avoid long sessions until tested. No webcam pixels are rendered; select only source tab, never entire screen. Face tracking uses continuous blendshape values, not 5000 individually authored animations. No hand tracking or full 3D. Browser/OS permissions and protected content may limit capture. Close page to release devices. Only use footage you have rights to use. Not browser-tested.
